# 잠자는 구름 숨쉬기 루프 영상

수채화 느낌의 잠자는 구름 캐릭터(`assets/sleeping_cloud.png`, 1254×1254, 배경 투명 PNG)를
**아기가 자면서 숨 쉬듯** 포근하게 움직이는 5초 무한 반복 영상으로 만드는 프로젝트.

## 요청 사항 (사용자)
- 5초 정도, 아기가 숨 쉬듯 자연스럽게. 부자연스러운 숨쉬기는 안 됨.
- 원본 그림을 유지하면서 조금 더 역동적으로, 구름 형태도 살짝살짝 바뀌게, 세련되게.
- 음영 효과 추가.

## 방식
AI 영상 생성(Runway, 힉스필드)은 두 계정 모두 무료 플랜이라 사용할 수 없었음
(Runway: 영상 모델 없음, 힉스필드: 크레딧 0.75).
그래서 `breathe.py`가 원본 그림을 OpenCV `remap`(역방향 워프)으로 직접 움직임.
캐릭터 얼굴과 선이 AI처럼 변형되지 않는다는 장점이 있음.

## 버전 기록 (`renders/`)
- `v1_breathing.mp4` — 숨쉬기만. 바닥 고정, 위쪽이 부풀음(세로 3.2%, 가로 1.4%).
  들숨 40%, 날숨 50%, 쉼 10%, 2.5초 주기로 5초에 2회.
- `v2_dynamic.mp4` — v1에 추가: 외곽 형태 변화(노이즈 9px, 얼굴은 거의 고정), 둥실 뜨기(±7px),
  기울기(±0.7°), 베개 구름이 반 박자 늦게 부풀음, 꼬리 흔들림(±4°), 들숨 때 볼 터치 진해짐,
  바닥 그림자(떠오르면 작고 옅어짐). 숨쉬기는 세로 4.2%, 가로 1.8%로 키움.
- `v3_shading.mp4` — v2에 볼륨 음영 추가. 왼쪽 위에서 빛이 비춤. 윗면은 따뜻한 크림색
  하이라이트, 아래와 옆면은 원본의 연보라 톤. 빛 방향은 천천히 움직이고 들숨 때
  하이라이트가 밝아짐. (`python breathe.py --v3`로 박자·크기·둥실 움직임을 v3처럼 되돌릴 수 있음)
- `v4_transparent.webm` — v3와 같은 움직임을 투명 배경으로 뽑은 것(VP9 알파, 약 1MB).
  바닥 그림자도 반투명 알파로 들어가서, 흰 배경 위에 올리면 v3 MP4와 똑같이 보임.
  웹페이지나 다른 영상 위에 바로 얹을 수 있음.
- `v5_natural.mp4` / `v5_natural.webm` — 숨 박자, 움직임 크기, 둥실 뜨는 정도를 더 자연스럽게 조정.
  **현재 최신 버전이며 `python breathe.py` 기본값과 같음.**
  - 숨 박자: 두 숨이 똑같지 않음. 첫 숨이 조금 길고 깊고(깊이 100%), 두 번째는 짧고 얕음(85%).
    길이는 2.65초와 2.35초. 들숨 38%, 날숨 56%, 멈춤 6%. 날숨은 처음엔 툭 풀리고
    끝은 천천히 가라앉음. v3는 날숨이 대칭 곡선이라 기계적이었고, 멈춤 구간도 더 길었음.
  - 움직임 크기: 깊은 숨 기준 세로 4.0%, 가로 1.6% (v3는 매번 4.2%, 1.8%).
  - 둥실: v3는 숨과 상관없는 5초짜리 사인파(±7px) 하나였음. v5는 느린 흐름(±3.5px)에
    숨을 따라 반 박자 늦게 떠오르는 움직임(+5px)을 더함. 깊은 숨에 크게, 얕은 숨에 작게 뜸.
    기울기도 느린 흔들림(±0.5°)에, 들숨 때 머리 쪽이 살짝 드는 움직임(0.25°)을 더함.

## 실행
```bash
pip install -r requirements.txt   # ffmpeg 필요
python breathe.py                         # → renders/out.mp4 (v5)
python breathe.py --v3                    # v3의 박자·크기·둥실 움직임으로 비교
python breathe.py --breath-var 0 --breath-swing 0   # 두 숨을 똑같게
python breathe.py --bob-breath 0          # 숨과 상관없이 천천히만 뜨게
python breathe.py --period 3              # 숨을 더 느리게 (반복 길이 6초)
python breathe.py --no-shading            # v2 느낌
python breathe.py --morph 14 --shade 0.6  # 형태 변화와 음영을 더 강하게
python breathe.py --light -45             # 빛을 오른쪽 위에서
python breathe.py --no-shadow             # 바닥 그림자 제거
python breathe.py --alpha                 # 투명 PNG 시퀀스도 출력 (프리미어/AE용)
python breathe.py --webm                  # 투명 WebM도 출력 (renders/out.webm, 웹·오버레이용)
python breathe.py --webm --no-shadow      # 그림자 없이 구름만 투명으로
```
전체 옵션은 `python breathe.py -h`로 확인.

## 반드시 지킬 것
- **반복 재생이 끊기면 안 됨.** 모든 움직임의 주기가 반복 길이(`breaths × period`)의
  정수배여야 함. 새 움직임을 넣을 때도 `w1`의 정수배 주파수만 쓸 것.
- **얼굴(눈, 입, 볼)은 변형하지 않음.** `face`와 `facezone` 마스크가 이 역할을 함.
- 움직임은 은은하게. 사용자가 원하는 건 "포근함"과 "세련됨"이지 과한 움직임이 아님.
- 좌표 기준은 1254px 원본(구름 범위 x 47–1185, y 357–905, 바닥 y≈905).

## 이전에 겪은 문제
- 음영 높이맵을 `distanceTransform`으로 만들면 안쪽에 방사형 줄무늬가 생김.
  가우시안 블러를 겹쳐 쓰는 지금 방식을 유지할 것.
- 프레임 반복문 안에서 음영 함수가 쓰는 전역 변수 이름(색상 등)을 덮어쓰면, 두 번째
  프레임부터 음영이 검게 변함. 실제로 `warm` 변수가 겹쳐서 이 문제가 났음.
- 음영을 색 곱하기(multiply)로 넣으면 탁한 회녹색이 됨. 목표 색으로 섞는 lerp 방식을 쓸 것.

- v3까지는 바닥 그림자가 거꾸로 움직였음(구름이 내려갈 때 그림자가 작아짐). v5에서 고침.
- v3까지는 볼 터치가 원래 위치에서 벗어나 몸과 반대로 움직였고, 너무 약해서 거의 보이지 않았음
  (최대 1.8단계). v5에서는 워프 전에 원본 위에 칠하기 때문에 볼에 붙어서 같이 움직임.
  위치는 원본에서 잰 (679,713), (975,620). 세기는 `--blush`(기본 0.35)로 조정.
- 숨마다 길이를 다르게 해도 길이 합이 반복 길이와 같으면 반복은 끊기지 않음(`DURS` 정규화).
