## 1️⃣ 해상 운송 (Ocean)

### 운송 형태

| 용어 | 풀네임 | 뜻 |
|---|---|---|
| FCL | Full Container Load | 컨테이너 한 대를 한 화주가 통째로 씀 |
| LCL | Less than Container Load | 여러 화주 화물을 한 컨테이너에 같이 실음 (혼재) |
| Consolidation | | 혼재. 소량 화물 여러 개를 모아 컨테이너 하나로 만듦 |
| Bulk | | 포장 없이 선창에 바로 싣는 화물 (곡물, 석탄, 광석) |
| Break Bulk | | 컨테이너에 안 들어가는 대형·중량 화물을 개별로 싣는 방식 |
| Ro-Ro | Roll-on Roll-off | 차량이 자기 바퀴로 배에 오르내림 (자동차 운송) |

### 컨테이너

| 종류 | 내부 용적 (약) | 실제 적재 가능 (약) | 용도 |
|---|---|---|---|
| 20' GP (DC) | 33 CBM | 25~28 CBM | 일반 화물, 무거운 화물 |
| 40' GP (DC) | 67 CBM | 55~58 CBM | 일반 화물 |
| 40' HC (HQ) | 76 CBM | 65~68 CBM | 높이가 약 30cm 더 높음. 부피 큰 화물 |
| RF (Reefer) | | | 냉장·냉동. 전원 연결 필요 |
| OT (Open Top) | | | 지붕이 열림. 높이 초과 화물 |
| FR (Flat Rack) | | | 벽·지붕 없음. 폭·높이 초과 중량물 |
| Tank | | | 액체 화물 |

- **TEU / FEU**: 20피트 / 40피트 컨테이너 1대 단위 (선박 크기, 물동량 표시)
- **Container No.**: 영문 4자리 + 숫자 7자리 (예: ABCU1234567)
- **Seal No.**: 컨테이너 봉인 번호. B/L과 일치해야 함
- **COC / SOC**: 선사 소유 컨테이너 / 화주 소유 컨테이너
- 실제 적재 중량은 도로 운송 중량 제한 때문에 컨테이너 최대 적재 중량보다 낮게 잡음

### B/L (Bill of Lading, 선하증권) 종류

> B/L은 **유가증권**. 원본(Original)을 가진 사람이 화물 주인이고, 배서로 양도 가능

| 종류 | 뜻 |
|---|---|
| Master B/L (MBL) | 선사가 포워더에게 발행 |
| House B/L (HBL) | 포워더가 화주에게 발행 |
| Original B/L | 원본 B/L. 보통 3통 발행(3/3), 1통만 제시하면 화물 인수 가능 |
| Surrender B/L | 출발지에서 원본을 반납(Surrender)하고 도착지에서 원본 없이 화물 인수. 근거리(중국·일본)에서 많이 씀 |
| Telex Release | Surrender 처리를 도착지에 전신으로 알리는 것 (실무에선 Surrender와 거의 같은 뜻) |
| Sea Waybill (SWB) | 처음부터 비유통 화물수취증. 원본 필요 없음 |
| On Board B/L | 본선 적재 후 발행 ("Shipped on board" + 날짜). L/C가 보통 요구 |
| Received B/L | 화물을 받았을 때 발행 (적재 전). 나중에 On board 표기 추가 가능 |
| Clean B/L | 화물 상태 이상 기재 없음 |
| Foul (Dirty) B/L | 화물 손상·수량 부족 등이 기재됨. L/C 거래에서 거절됨 |
| Straight B/L | 기명식. Consignee에 수입자 이름 기재, 양도 불가 |
| Order B/L | 지시식. Consignee에 "To order (of ○○ Bank)" 기재, 배서로 양도. L/C 거래에 많이 씀 |
| Switch B/L | 중계무역에서 원래 B/L을 회수하고 내용을 바꿔 재발행 |

- **B/L 주요 기재 항목**: Shipper, Consignee, Notify Party, Vessel/Voyage, POL/POD, Container/Seal No., 품명·수량·중량·CBM, Freight Prepaid/Collect, 발행지·발행일, 원본 통수

| 용어 | 언제 발생 | 누구에게 |
|---|---|---|

- **General Average (공동해손)**: 배와 화물 전체를 구하려고 일부 화물을 버리거나 비용이 생기면 모든 화주가 나눠 부담. 화주가 보험에 들어둬야 하는 이유 중 하나

### AWB (Air Waybill, 항공화물운송장)

> AWB는 B/L과 달리 **유가증권이 아님**. 화물 수취증 겸 운송계약 증빙이라 양도 불가(비유통), 항상 **기명식**

| 항목 | 내용 |
|---|---|
| MAWB | Master AWB. 항공사가 포워더에게 발행 |
| HAWB | House AWB. 포워더가 화주에게 발행 |
| 번호 | 11자리 = 항공사 Prefix 3자리 + 일련번호 8자리 (예: 180 대한항공, 988 아시아나) |
| 원본 | 3부. Original 1 항공사용, Original 2 수하인용, Original 3 송하인용 |
| 화물 인도 | 원본 제시 없이 AWB에 적힌 Consignee에게 인도 |

### 중량·운임 (계산 문제 단골 ⭐)

**Chargeable Weight (C.W, 운임 부과 중량)**
- 실중량(G.W)과 부피중량(Volume Weight) 중 **큰 값**
- 부피중량(kg) = 가로 × 세로 × 높이 (cm) ÷ **6,000** (IATA 기준, 1 CBM ≈ 167kg)
- 특송사는 보통 ÷ **5,000** 적용
- 0.5kg 단위로 올림

**운임 구간 (Weight Break)**
- M (Minimum): 최저 운임
- N (Normal): 45kg 미만
- Q (Quantity): +45 / +100 / +300 / +500 / +1,000kg. 무게가 클수록 kg당 단가가 내려감
- Break Point: 다음 구간 최저 중량으로 계산하는 게 더 싸지는 지점

| 운임 종류 | 뜻 |
|---|---|
| GCR | General Cargo Rate. 일반 화물 운임 |
| SCR | Specific Commodity Rate. 특정 품목 할인 운임 |
| Class Rate | 품목별 할증·할인 운임 (귀중품, 생동물 등) |

| 부대비용 | 풀네임 | 뜻 |
|---|---|---|
| FSC | Fuel Surcharge | 유류할증료 |

## 3️⃣ 해상 vs 항공 한눈에 비교

| 구분 | 해상 | 항공 |
|---|---|---|
| 운송서류 | B/L (유가증권, 지시식 가능) | AWB (비유통, 항상 기명식) |
| 운임 기준 | FCL: 컨테이너당 / LCL: R.T (1 CBM = 1,000kg) | C.W (1 CBM ≈ 167kg, ÷6,000) |
| 주요 할증료 | BAF, LSS, CAF, PSS, GRI | FSC, SSC |
| 화물 처리 시설 | CY, CFS | 항공사 터미널, 공항 보세창고 |
| 소량 화물 | LCL (CFS 혼재) | Consol (MAWB 혼재) |
| 운송 기간 | 길다 (근거리 수일, 원거리 수주) | 짧다 (보통 1~3일) |
| 비용 | 저렴 | 비쌈 |
| 지체료 | DEM, DET, Storage | Storage (창고 보관료) |
| 원본 없이 인도 | Surrender B/L, Sea Waybill | 기본이 원본 없이 인도 |
| 이런 화물에 | 대량·저가·무거운 화물 | 소량·고가·긴급·신선 화물 |

## 4️⃣ 업무 흐름 (Process)

### 해상 FCL 수출
1. 견적 (Quotation)
2. 부킹 (Booking), 선사 스케줄 확정
3. 공컨테이너 반출 (Pick-up)
4. 화주 공장에서 적입 (Stuffing), Seal 부착
5. 수출신고·수리
6. CY 반입, VGM 제출
7. S/R 제출 (서류 마감 전)
8. 선적 (On Board)
9. B/L Draft 확인 → B/L 발행 (Original 또는 Surrender)
10. 출항 → 도착지 파트너에게 서류 전달

### 해상 FCL 수입
1. 도착 통지 (A/N) 수령
2. 운임·부대비 정산
3. D/O 발급
4. 수입신고·관세 납부
5. 컨테이너 반출 → 내륙 운송
6. 적출 (Devanning)
7. 공컨테이너 반납 (늦으면 Detention)

### 해상 LCL
화주 → **CFS 반입** → 혼재 적입 → CY → 선적 → 도착지 CFS **적출·분류** → 수입신고 → 반출

### 항공 수출
1. 부킹 (항공사 공간 확보)
2. 공항 보세창고 반입
3. 수출신고·수리
4. 보안 검색 (X-ray)
5. 계근·실측 → **C.W 확정**
6. AWB 발행
7. 항공사 인계, ULD 적재 (Build-up)
8. 출발

### 항공 수입
도착 → 항공사 창고 반입·분류 (Break-down) → A/N → 수입신고 → D/O → 반출 → 배송

## 5️⃣ 계산 연습

**① 해상 LCL 운임**
- 화물: 3 CBM, 1,500kg / 운임 USD 30 per R.T
- R.T = max(3 CBM, 1.5 ton) = **3 R.T**
- 운임 = 3 × 30 = **USD 90**

**② 항공 Chargeable Weight**
- 박스 2개, 각각 100 × 80 × 60 cm, 40kg
- 부피중량 = 100 × 80 × 60 ÷ 6,000 = 80kg × 2개 = **160kg**
- 실중량 = 40kg × 2개 = 80kg
- C.W = max(160, 80) = **160kg** (부피 화물)

**③ 컨테이너 고르기**
- 화물 50 CBM → 20' 2대보다 **40' GP 1대**가 보통 더 저렴
- 화물 62 CBM → 40' GP로는 빠듯하므로 **40' HC**
- 무겁고 부피 작은 화물 (예: 철강 20톤, 10 CBM) → **20' GP** (도로 중량 제한 확인)

## 6️⃣ 셀프 체크 (면접 대비)

1. **B/L과 AWB의 가장 큰 차이는?**
   B/L은 유가증권이라 배서로 양도할 수 있고, 원본을 제시해야 화물을 인수함. AWB는 비유통 화물수취증이라 기명된 수하인에게 바로 인도함
2. **Demurrage와 Detention의 차이는?**
   DEM은 컨테이너가 CY 안에 Free Time을 넘겨 머무는 것, DET는 반출한 컨테이너 반납이 늦어지는 것
3. **Surrender B/L은 언제 쓰나?**
   중국·일본처럼 운송 기간이 짧아 원본 B/L이 화물보다 늦게 도착할 수 있을 때, 또는 대금 결제가 끝난 거래일 때
4. **항공 운임이 실중량보다 부피로 계산되는 경우는?**
   부피중량(cm³ ÷ 6,000)이 실중량보다 클 때. 가볍고 부피 큰 화물
5. **MBL과 HBL의 차이는?**
   MBL은 선사가 포워더에게, HBL은 포워더가 화주에게 발행
6. **VGM을 안 내면?**
   SOLAS 규정상 선적 불가
